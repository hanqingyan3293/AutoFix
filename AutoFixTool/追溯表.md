# AutoFix 功能追溯表

本表记录每个功能与原程序 `Autobox 1.0.4` 的对应关系，供维护、验证与合规对照使用。

- **原程序方法**：`Autobox1.0.4.exe` 反编译后（`decompiled/`）对应的方法名
- **本实现位置**：`AutoFixTool/` 中的文件
- **关系**：`重写` = 读原逻辑后独立重新实现；`新增` = 原程序没有，本项目增加；`改判据` = 逻辑沿用但判断条件被有意调整

## 有意偏离原实现之处

| 项目 | 原实现 | 本实现 | 原因 |
| --- | --- | --- | --- |
| 目录权限授予对象 | `takeown` + `icacls ... Everyone:(OI)(CI)F` | 当前用户 / Administrators / Users | 给 Everyone 完全控制是安全倒退 |
| hosts 修复判据 | 只清除 `rj818.com` 相关条目 | 清除所有屏蔽 Autodesk 相关域名的条目 | 原逻辑服务于特定厂商域名，改为通用 |
| 3ds Max 语言切换 | 硬编码 `3dsMax\15.0`–`26.0` 共 12 个版本键 | 枚举 `HKCU\SOFTWARE\Autodesk\3dsMax` 下实际存在的子键 | 新版本自动覆盖，不误写不存在的版本 |
| CAD 版本降级 | 找不到 ODA 时联网下载并自动安装 | 只使用本机已安装的 ODA，找不到则提示手动安装 | 保持完全离线运行 |
| 错误4000 / 错误-9 | 删除 `SOFTWARE\Classes` 下所有叶子键 | **行为一致**（未收窄） | 忠实还原；风险已在使用前提示 |
| 错误3 | 删除 `C:\ProgramData` 下名称含特殊字符的目录 | **行为一致**（未收窄） | 同上 |

## 代码来源说明

本项目代码**不是**对原程序的反编译拷贝，而是阅读其行为后独立重新实现：

- `decompiled/` 是原程序的反编译产物（属原程序表达，默认不入库，见 `.gitignore`）
- `AutoFixTool/` 是本项目的重写实现
- 实测：与本项目相关的原程序文件中，逐字相同且超过 24 字符的代码行约 77 行（占本实现的约 5%），
  主要集中于 Win32 API 声明、`IEmptyVolumeCache` 接口签名、版本码映射表、GUID 与注册表路径等无法改写的内容
- 沿用自原程序的：具体注册表分支、账户权限组合与继承标志、服务名与进程名、目录路径、GUID、版本码表、操作顺序、错误码对应关系
